# Device Switch v0.1

First public release for Windows x64. Requires the .NET 10 Desktop Runtime.

- Switch monitor inputs through Windows DDC/CI and Logitech devices through their USB receiver.
- Manage multiple profiles in one editor, with monitor discovery, input names and an input setup guide.
- Discover receiver slots and Change Host features; test individual devices or the complete profile.
- Run a saved profile directly, for example `SoftwareDeviceSwitch.exe -Work-PC`.
- Assign conflict-checked global shortcuts, including German `Ctrl + Alt + <` combinations.
- Keep the tool in the system tray and optionally start it at Windows sign-in.

Download the standalone `SoftwareDeviceSwitch.exe`, or extract the portable ZIP to a writable folder. The ZIP includes an empty starter `profile.json` and a quick-start guide. Existing users should keep their own `profile.json` when updating the executable. SHA-256 checksums are included.

Monitor input codes and DDC/CI behavior vary by manufacturer. Input switching does not guarantee that the destination computer is sending a video signal. Bluetooth switching and device pairing are not included. Shortcut conflict checks cover registered global hotkeys; shortcuts handled only inside other applications cannot be detected.
